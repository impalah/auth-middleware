Bases: BaseHTTPMiddleware

JWT Authorization middleware for FastAPI Adds the current user to the request state.

Every option below is keyword-only and defaults to the historical behaviour.

Parameters:

  • app – The ASGI application.

  • auth_provider – The JWT provider validating tokens.

  • canonical_bearer_scheme – Treat the Authorization scheme case-insensitively (RFC 7235): bearer/BEARER are rewritten to Bearer before validation. Other schemes keep their own rejection status.

  • path_prefix – Only requests whose path equals the prefix or starts with prefix + "/" are authenticated; others skip the middleware entirely and request.state.current_user is not set for them. Useful when other apps are mounted inside this one with their own middleware.

  • error_responder – Builds the response for invalid token, bad scheme and internal errors from (request, AuthFailure). The default keeps the {"detail": ...} JSON bodies.

  • strict – Raise RuntimeError at construction when AUTH_MIDDLEWARE_DISABLED is set or the provider’s settings have jwt_token_verification_disabled=True.
